# 경신 런치리그 2학년

2026학년도 2학기 경신고등학교 2학년 런치리그 일정, 결과, 순위, 토너먼트 페이지.

## 보기

GitHub Pages 주소로 누구나 볼 수 있다. 1분마다 새 결과를 불러온다.

## 수정하기 (관리자)

1. https://github.com/settings/personal-access-tokens/new 에서 토큰을 만든다.
   - Repository access: Only select repositories, 이 저장소만 선택
   - Permissions: Contents를 Read and write로
2. 페이지 오른쪽 위 자물쇠를 눌러 토큰을 넣는다. 토큰은 그 기기 브라우저에만 저장된다.
3. 경기를 누르면 점수, 승부차기, 날짜를 고칠 수 있다. 저장하면 `data.json`에 커밋된다.

### 일정이 밀렸을 때

- 경기 편집에서 **다음 경기일로**를 누르고 **뒤 경기도 같은 만큼 미루기**를 켠 채 저장하면, 그 경기와 뒤 경기들이 모두 한 경기일(월, 수)씩 밀린다.
- **일정 편집**에서는 모든 경기 날짜를 한 화면에서 고치고, 경기마다 미루기 버튼으로 뒤 경기까지 함께 밀 수 있다.

### 팀 꾸미기, 대회 로고

- **팀 꾸미기**: 팀마다 이름, 팀 컬러, 로고를 바꿀 수 있다. 바꾼 색과 로고는 경기 목록, 경기 상세 헤더, 팀 페이지, 순위표, 토너먼트 승자 경로, 우승 카드에 모두 쓰인다.
- **대회 로고**: 맨 위 대회 로고, 대회 이름, 브라우저 탭 아이콘을 바꾼다.
- 올린 이미지는 브라우저에서 160px로 줄여 `data.json` 안에 저장된다. 따로 파일을 올릴 필요가 없다.

## 순위와 대진

- 조별 리그: 승점, 골득실, 다득점 순. 승리 3점, 무승부 1점, 패배 0점.
- 와일드카드: 각 조 2위 중 같은 기준으로 1팀.
- 준결승 1: A조 1위 vs B조 1위, 준결승 2: C조 1위 vs 와일드카드, 결승: 두 승자.
- 조별 리그가 끝나면 대진이 자동으로 채워진다. 모든 기준이 같으면 `?`로 표시되고, 관리자가 추첨 결과를 넣으면 채워진다.

## 파일

- `index.html`, `style.css`, `app.js`: 화면
- `league.js`: 순위, 동률, 대진, 일정 미루기 계산
- `data.json`: 경기 데이터 (앱이 직접 고친다)
