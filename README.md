# 경신 런치리그 2학년

2026학년도 2학기 경신고등학교 2학년 런치리그 일정, 결과, 순위, 토너먼트, 득점 기록 페이지.

## 보기

GitHub Pages 주소로 누구나 볼 수 있음. 1분마다 새 결과를 불러옴.

- **경기**: 맨 위에 다음 경기(또는 오늘 결과)가 크게 나옴. 아래는 경기일 1, 2, 3과 준결승, 결승으로 나뉨. 날짜에 맞춰 가장 최근 경기가 있는 경기일이 먼저 열림.
- **순위**: 조별 순위, 와일드카드 경쟁, 순위 결정 기준.
- **토너먼트**: 준결승과 결승 대진, 우승팀.
- **기록**: 득점 순위와 팀 득점.
- 경기를 누르면 득점자와 승부차기 기록, 팀을 누르면 팀 페이지가 열림.

## 수정하기 (관리자)

1. https://github.com/settings/personal-access-tokens/new 에서 토큰을 만듦.
   - Repository access: Only select repositories, 이 저장소만 선택
   - Permissions: Contents를 Read and write로
2. 페이지 오른쪽 위 자물쇠를 눌러 토큰을 넣음. 토큰은 그 기기 브라우저에만 저장됨.
3. 경기를 누르면 점수, 득점자, 승부차기, 날짜를 고칠 수 있음. 저장하면 `data.json`에 커밋됨.

### 득점자

- 선택 사항. **+ 팀 득점** 버튼으로 한 골씩 추가. 이름만 넣어도 되고, 분과 자책골은 필요할 때만 넣음.
- 득점자를 추가하면 점수가 부족할 때 자동으로 올라감.
- 한 번 넣은 이름은 다음부터 자동 완성으로 뜸.

### 승부차기

- 동점이면 조별 리그, 토너먼트 모두 승부차기 칸이 나타남.
- 조별 리그 승부차기는 기록만 남고 승점은 무승부(1점)로 반영됨.
- 키커 칸을 누를 때마다 성공, 실패, 빈칸 순으로 바뀜. 합계는 자동 계산.
- 5번째 키커까지 기본으로 나오고, **+ 서든데스**로 칸을 더 늘릴 수 있음.

### 일정이 밀렸을 때

- 경기 편집에서 **다음 월, 수로**를 누르고 **뒤 경기도 같은 만큼 미루기**를 켠 채 저장하면, 그 경기와 뒤 경기들이 모두 다음 월, 수로 한 칸씩 밀림.
- **일정 편집**에서는 모든 경기 날짜를 한 화면에서 고치고, 경기마다 미루기 버튼으로 뒤 경기까지 함께 밀 수 있음.

### 팀 꾸미기, 대회 로고

- **팀 꾸미기**: 팀마다 이름, 팀 컬러, 로고를 바꿀 수 있음. 바꾼 색과 로고는 경기 목록, 다음 경기 카드, 경기 상세 헤더, 팀 페이지, 순위표, 토너먼트 승자 경로, 우승 카드, 득점 1위 카드에 모두 쓰임.
- **대회 로고**: 맨 위 대회 로고, 대회 이름, 브라우저 탭 아이콘을 바꿈.
- 올린 이미지는 브라우저에서 160px로 줄여 `data.json` 안에 저장됨. 따로 파일을 올릴 필요 없음.

## 순위와 대진

- 조별 리그: 승점, 골득실, 다득점 순. 승리 3점, 무승부 1점, 패배 0점. 승부차기는 승점에 영향 없음.
- 와일드카드: 각 조 2위 중 같은 기준으로 1팀.
- 준결승 1: A조 1위 vs B조 1위, 준결승 2: C조 1위 vs 와일드카드, 결승: 두 승자.
- 조별 리그가 끝나면 대진이 자동으로 채워짐. 모든 기준이 같으면 `?`로 표시되고, 관리자가 추첨 결과를 넣으면 채워짐.

## 파일

- `data.json`: 경기 데이터 (앱이 직접 고침)
